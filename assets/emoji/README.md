# Color Emoji assets

Seven official Twemoji 14.0.2 PNGs, consistent 72 × 72 RGBA originals. Artwork by Twitter, Inc. and other contributors, licensed **CC BY 4.0**. Source: <https://github.com/twitter/twemoji/tree/v14.0.2/assets/72x72>. License: <https://creativecommons.org/licenses/by/4.0/>. Full license is in `LICENSE-GRAPHICS`; exact source URLs and SHA-256 hashes are in `manifest.json`.

The renderer scales, softly shadows, rotates and animates these images. No platform font fallback or monochrome glyphs are used. The project does not claim ownership of the Emoji artwork. Please retain this attribution when distributing the source or rendered video (for example in its post description).
